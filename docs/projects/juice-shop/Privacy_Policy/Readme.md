## Goal of this Challenge: 
The goal of this challenge is to navigate to the Privacy Policy site of the OWASP Juice Shop. 

## Type of Cyberattack
This is a Miscellaneous Security Vulnerability 

## Consequences of this Vulnerability
If a sensitive file such as the privacy policy is accessible in an unexpected location, an attacker may assume that additional security weaknesses exist and continue probing the application for further vulnerabilities.

## Disclaimer
The vulnerabilities and exploits shown in this repository are provided strictly for educational purposes. Do not attempt to use these techniques on systems without clear and explicit authorization.


## Description of Solution: 
1. Create an account on your OWASP Juice Shop. 
Navigate: 
```
Account-Login-"Not yet a customer" 
```

![Example Banner](/assets/images/Navigate_login.png)

2. Fill in your own email address and password 
![Example Banner](/assets/images/Registration.png)

3. Login with your created account. Alternatively, you can use the Admin Account from your SQL Admin Attack. 

4. Navigate to Account-Privacy&Security-Privacy Policy 
![Example Banner](/assets/images/navigation_privacy.png)


You got it!
